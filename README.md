
Этот бот представляет собой многофункциональный Telegram-помощник для отслеживания здоровья. Он разработан для пользователей, которые хотят контролировать своё самочувствие, получать информацию о лекарствах и устанавливать напоминания.

Основной функционал:
Регистрация пользователей:
Приветственное сообщение и обязательная регистрация по команде /register.
Хранение данных пользователей (имя, ID, статус бана) в базе данных SQLite.

Главное меню (интерактивные кнопки):
После регистрации пользователю доступны 5 основных функций:

1️ Выбрать категорию симптомов:
Пользователь выбирает область беспокойства (Голова, Живот и т.д.) и подробно описывает симптомы. Информация логируется для дальнейшего анализа.

2️ Найти лекарство/аналоги:
Поиск по встроенной базе лекарств. Бот возвращает информацию о действующем веществе, показаниях и список аналогов (например, для "Парацетамола" найдет "Панадол").

3️ Экстренная помощь:
Выводит справочную информацию: номера телефонов экстренных служб (скорая, полиция) и краткие инструкции по оказанию первой помощи (кровотечение, ожоги, инсульт).

4️ Дневник самочувствия:
Добавить запись: Пользователь выбирает настроение (с эмодзи), описывает симптомы и оставляет заметки. Все записи сохраняются в БД.
Просмотреть записи: Выводит последние 5 записей из дневника пользователя с датой и подробностями.

5️ Напоминание о приёме лекарства:
Добавить напоминание: Пользователь вводит название лекарства, дозировку, время (в формате ЧЧ:ММ) и частоту приема. Данные сохраняются.

6 Просмотреть напоминания: Выводит список всех активных напоминаний пользователя с указанием времени и статуса.

7 Админ-панель (команда /admin):
Доступна только для заранее указанных ADMIN_IDS.
Позволяет просматривать список последних зарегистрированных пользователей (с указанием статуса бана).
Дает возможность забанить или разбанить пользователя по его Telegram ID.

8 Система безопасности:
Проверка пользователя при каждом действии: забанен ли он и зарегистрирован ли.
Заблокированные пользователи не могут взаимодействовать с ботом.
Обработка ошибок:

Реагирует на неизвестные команды и сообщения, возвращая пользователя в главное меню.

Команда /cancel позволяет выйти из любого диалога (ConversationHandler).

Техническая реализация: Бот написан на Python с использованием библиотеки python-telegram-bot (v20+), использует SQLite для хранения данных и ConversationHandler для организации многошаговых диалогов.
